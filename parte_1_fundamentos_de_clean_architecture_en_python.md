# Parte 1: Fundamentos de Clean Architecture en Python

Esta parte establece los principios y patrones fundamentales de **Clean Architecture** en el contexto de Python. Obtendrás una comprensión integral de los conceptos arquitectónicos centrales, los principios **SOLID** y cómo el sistema de tipos de Python puede mejorar tus implementaciones arquitectónicas. Estos capítulos proporcionan la base de conocimiento esencial sobre la cual se construye el resto del libro, preparándote para el éxito en la implementación de Clean Architecture en tus propios proyectos de Python.

Esta parte del libro incluye los siguientes capítulos:

- [Capítulo 1](https://subscription.packtpub.com/book/programming/9781836642893/1), **Fundamentos de Clean Architecture: Transformando el desarrollo en Python**
- [Capítulo 2](https://subscription.packtpub.com/book/programming/9781836642893/2), **Fundamentos de SOLID: Construcción de aplicaciones robustas en Python**
- [Capítulo 3](https://subscription.packtpub.com/book/programming/9781836642893/3), **Python mejorado con tipos: Fortaleciendo Clean Architecture**
