# Parte 3: Aplicación de Clean Architecture en Python

La parte final demuestra cómo aplicar los principios de **Clean Architecture** en escenarios del mundo real y en diversos contextos. Implementarás una interfaz web completa, agregarás funciones de observabilidad manteniendo la integridad arquitectónica, transformarás sistemas heredados (*legacy*) mediante refactorización incremental y adaptarás Clean Architecture a diferentes tipos de sistemas y entornos organizacionales. Estos capítulos proporcionan una guía práctica para extender Clean Architecture más allá de nuestra aplicación de ejemplo para abordar desafíos complejos del mundo real.

Esta parte del libro incluye los siguientes capítulos:

- [Capítulo 9](https://subscription.packtpub.com/book/programming/9781836642893/9), **Adición de UI Web: La flexibilidad de interfaces de Clean Architecture**
- [Capítulo 10](https://subscription.packtpub.com/book/programming/9781836642893/10), **Implementación de observabilidad: Monitorización y verificación**
- [Capítulo 11](https://subscription.packtpub.com/book/programming/9781836642893/11), **De código heredado a Clean: Refactorización en Python para la mantenibilidad**
- [Capítulo 12](https://subscription.packtpub.com/book/programming/9781836642893/12), **Tu viaje con Clean Architecture: Próximos pasos**
